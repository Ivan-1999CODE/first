# Travel Lab：成人旅遊英文

下載兩個 HTML 檔與 assets 資料夾，保持原本目錄結構，用瀏覽器開啟 `travel-english.html`。不需要安裝套件，也不需要伺服器。

- UNIT 01：問路與求助。郵局、公車站、警局、火車站、銀行、超市分組地圖；兩步練習：先自己試著說，再聽完追問。
- UNIT 02：第二天購物。服飾店分支互動（先開口，再點選行動）、預算、尺寸、付款與四種店家的雙人角色練習。

每個單元包含分層提示、課後自學與 TXT 匯出。UNIT 01 已移除教師筆記；雙人任務提供 6 段內嵌語音，左側聽提問、右側點地圖，另附步行與計程車額外練習。其餘英文朗讀使用裝置語音；若無法播放可展開文字。自由作答由教師或同儕回饋，不提供自動文法評分。

資料僅保存在本機瀏覽器，單元間獨立保存。UNIT 01 新版使用新的進度儲存區，避免舊情境答案被配到新題目；舊版儲存資料並未刪除。

## UNIT 01 教學安排

1. 課前紀錄：先用已知英文表達。
2. 核心問法先選 2–3 種；禮貌問句與 nearest 當延伸。
3. 每輪地圖顯示 4 個地點，共 6 個地點；聽路線、選地點。
4. 兩步表達：先自己試著說 → 聽完再追問。提示預設收起，點開只提供關鍵詞與句子開頭。
5. 雙人資訊差活動、前後比較、課後練習。

第一、第二單元可透過頁面連結互相切換。本儲存庫不包含學生作答紀錄。

## UNIT 02 教學調整

第三部分以服飾店場景互動：點選衣架上的藍色、粉紅色、綠色 T-shirt，再詢問 S／M／L 尺寸、試穿許可與更衣間位置。聽完店員指示後點鏡子旁的更衣間；試穿後可表達合身、太大或太小，換尺寸或繼續問價與付款。店員語音可重播與慢速播放，英文文字和開口提示預設收起。第四部分整理購物說法，第五部分以禮品店、服飾店、鞋店、超市進行雙人資訊差任務。課後練習與自評聚焦店員互動。

分支依學生點選的中文行動推進，不使用語音辨識。服飾店的本輪分支在重新整理後重設；原有書面答案仍保存並可匯出。新版沿用舊版書面答案，僅重設已改為店員聽力的第一項自評與第一項課後勾選，舊儲存資料保留。

第三部分採左側店員引導、右側服飾場景。每輪分成聽店員、開口回應、點選行動；學生自行確認已開口後才開放選擇（不是語音辨識）。提示旁的小燈泡須先展開提示，並確認「真的要看解答嗎？」才顯示完整建議。重新開始按鈕位於店員卡片右上角。

第五部分 B 店員角色新增紀念品小店：先聽顧客音檔，從 postcard、cap、cup、hat、T-shirt、shoes 選商品，再聽問價並口頭報價。提供 8 個 Windows Zira 英文合成語音 WAV 檔（assets/customer-audio），支援重播、慢速與文字提示；若音檔播放失敗會嘗試裝置朗讀。鞋子使用 How much are they?／They’re…，單件商品使用 How much is it?／It’s…。原有四種店家的角色卡保留在可展開區。
