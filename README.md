# Travel Lab：成人旅遊英文

下載兩個 HTML 檔並放在同一資料夾，用瀏覽器開啟 `travel-english.html`。不需要安裝套件，也不需要伺服器。

- UNIT 01：問路與求助。郵局、公車站、警局、火車站、銀行、超市分組地圖；三輪練習從句型、需求選擇走向追問。
- UNIT 02：第二天購物。導航、預算、尺寸、付款與雙人角色練習。

每個單元包含教師筆記、分層提示、課後自學與 TXT 匯出。英文朗讀使用裝置語音；若無法播放可展開文字。自由作答由教師或同儕回饋，不提供自動文法評分。

資料僅保存在本機瀏覽器，單元間獨立保存。UNIT 01 新版使用新的進度儲存區，避免舊情境答案被配到新題目；舊版儲存資料並未刪除。

## UNIT 01 教學安排

1. 課前紀錄：先用已知英文表達。
2. 核心問法先選 2–3 種；禮貌問句與 nearest 當延伸。
3. 每輪地圖顯示 4 個地點，共 6 個地點；聽路線、選地點。
4. 三輪表達：帶句型起步 → 只看需求、自己選地點與問法 → 根據新資訊追問。
5. 雙人資訊差活動、前後比較、課後練習。

第一、第二單元可透過頁面連結互相切換。本儲存庫不包含學生作答紀錄。
