# 共用介面、外觀與資料規則

這些規則適用於整個新單元。第七天為格式參考，不能因換主題而省略頁首控制、導覽、狀態回饋或自動保存。修改既有單元時只處理授權範圍，保留使用者紀錄。

## 1. 全頁版面與導覽

```text
┌ Travel Lab／品牌短句                  [放大文字] [☾ 深色] ┐
├ 切換單元：第 1 天  第 2 天  ……  第 N 天                    ┤
│ 本單元七部分選單       │ 主內容區                          │
│ 01 課前嘗試            │ 短標／標題／一句操作說明          │
│ 02 隨身句與短問答      │ 本部分固定區塊                    │
│ 03 互動流程            │                                  │
│ 04 特定情況            │                                  │
│ 05 師生共練            │                                  │
│ 06 看看我的進步        │ [上一部分]           [下一部分]   │
│ 07 課後挑戰            │                                  │
├ 全部課程／相鄰單元連結                                    ┤
```

- 頁首在捲動時維持可用，放大文字及深淺色控制固定在右側，不隨七部分切換消失。
- 「切換單元」是不同天的檔案連結；「七部分選單」是本天內容切換，不能混成同一層導覽。
- 當前天數與當前部分各自標明選取狀態；支援 `aria-current`。模式和情境按鈕則有 `aria-pressed` 或等效可存取語意。
- 桌面左側七部分選單、右側主內容；第七天以約 235 px 側欄、約 1480 px 最大容器為參考。數字可因專案調整，但保留清楚的雙區結構。
- 內容變窄時（第七天約 1100 px）改成上方可收合「課程選單」；手機不壓縮成窄側欄。選單必須能真正開合，所有項目仍能到達。
- 兩欄卡片在手機上下排列。第五部分的教師引導可放在任務卡上方的收合列，讓老師易找；預設仍收起，不遮住任務。
- 切部分後停止舊語音，將焦點移到主內容的標題或容器並回到適當位置；切模式／題組後焦點仍在可理解的位置。不要因更新整個區塊而丟失鍵盤焦點。
- 新增一個單元時，更新首頁與既有單元的切換列，使所有已存在的單元互相可達；同步檢查建置模板，避免下一次建置又漏掉新天數。只新增導覽連結不代表可自行重做舊課內容。

## 2. 視覺與閱讀層級

- 使用系統字體，兼顧繁體中文與英文。文字本身可選取，不把題目文字烘焙在圖片裡。
- 主標題、中文任務、英文練習句、按鈕及次要說明各有清楚層級；學生要回答的任務和老師下一句英文要容易找到。
- 參考尺度：正文約 17 px 起，任務句約 20–22 px，重點英文約 22–26 px，主卡片內距約 24–30 px；手機可調整間距，不靠把重要文字縮很小來塞版。
- 使用柔和背景、圓角卡片、有限主題色與適當留白。主內容卡、提示區、選取狀態與回饋區要分得出來，不只靠色差很小的裝飾。
- 重要控制保留文字標籤；播放、月亮、太陽等圖示可輔助，但不以圖示取代可理解名稱。
- 按鈕／展開列提供至少約 44 px 的可操作高度、清楚焦點與按下回饋。錯誤、成功、未完成及選取不能只用顏色表示。
- 依內容建立 SVG／CSS 或其他合適插圖；優先使用可依狀態變動的物件。人物或衣架等裝飾不占掉主要任務空間。

## 3. 頁首固定功能

### 放大文字

- 顯示「放大文字」；啟用後變成「標準文字」，選取狀態清楚，再按即可恢復。
- 放大的是學生要讀的正文、任務、英文句子、提示與控制文字；不是把整個畫面縮放到水平捲動，也不是只放大標題。
- 放大後允許卡片增高與重新排列，不能裁切按鈕或把句子蓋住。
- 新教材保存文字大小偏好。延續專案時可使用共用設定 key，如 `travel-lab-text-size`，值為 `standard`／`large`。先確認是否已有命名，不製造兩套設定。
- 第七天現有版本的放大文字只在當次頁面有效；它提供按鈕格式參考。依本規格做新教材時須補上偏好保存，不能以案例的限制當成新功能已實作。

### 深淺色切換

- 未設定時預設淺色。淺色時按鈕顯示「☾ 深色」，表示按下切到深色；深色時顯示「☀ 淺色」。可存取名稱分別為「切換為深色模式／切換為淺色模式」。
- 使用者選擇後立即變更，並保存；第七天已有共用 key `travel-lab-theme`，值為 `light`／`dark`。後續同來源教材沿用，不每一課另創不相通的外觀 key。
- 初始渲染前套用有效的已存設定，避免深色使用者每次開頁先閃白。無效值或無法讀取時回預設，不能讓頁面起不來。
- 背景、頁首、卡片、導覽、按鈕、欄位、placeholder、提示、回饋及焦點一起設計。不要只將 body 改黑，也不要把整頁反相。
- 插圖的資訊色保留正確意義，例如藍色衣服仍是藍色；必要時調整圖的背景、邊框與文字標籤。
- 三格自評在深色仍依 1 格黃、2 格黃、3 格綠呈現，未選部分為中性色。不要讓通用已選按鈕樣式蓋掉自評顏色。
- 尊重減少動態、減少透明度及提高對比；深色模式也要檢查這些偏好。文字、控制邊界與焦點採適用的可存取對比標準檢查。
- 設定不能保存時，當次切換仍有效，提供簡短提示即可；不要用下載設定檔或匯出作為替代。

**範圍界線：**新教材必備兩個控制；既有其他天尚未支援時，不宣稱選一次就能讓舊頁一起變色。只有讀取同一共用設定且已實作外觀的頁面才能維持一致。

## 4. 語音、提示與無障礙

- 英文朗讀使用實際可用的瀏覽器或專案語音能力，設定適合英文的語言；一般與慢速都讀同一內容。不要假設所有電腦一定有同一聲音。
- 開始另一句、切情境、切部分或離開頁面時停止上一句，不疊音。
- 音訊不可用時用簡短文字說明，學生可展開逐字稿繼續；不要把無語音當成無法完成課程。
- 使用真正的 button、label、textarea、checkbox 與 details／summary 或同等可存取元件。提示預設收合，鍵盤可展開與收起。
- 朗讀不自動改成「已聽懂」，勾選已開口不代表辨識到聲音。不要要求麥克風權限或加入假錄音狀態。
- 英文標示適當 `lang`；角色插圖純裝飾時不要讓讀屏重複朗讀，帶有答案資訊的物件需有可理解文字標籤。
- 動作須可用鍵盤完成；focus-visible 保留；切換和回饋用合適的狀態文字或 live region，避免每一次重繪都重念整頁。

## 5. 資料結構與保存界線

以穩定的內容識別碼保存，數量改變時不錯配舊答案。延續既有陣列資料時先兼容讀取，不為「整理結構」刪掉學生紀錄。

| 資料 | 是否跨重新開啟保存 | 原因／規則 |
| --- | --- | --- |
| 課前回答、課後回答 | 是，各自分開 | 可前後比較，課後不覆蓋課前 |
| 第四部分各情境回答 | 是，依情境分開 | 切情境不丟失、不串題 |
| 第五部分各任務目標勾選 | 是，依任務分開 | 老師可繼續檢視及取消勾選 |
| 師生練習筆記、課後口說紀錄 | 是 | 保存使用者輸入；原有共用筆記要兼容 |
| 各能力自評、完成的流程、課後勾選 | 是 | 保持學習紀錄，不當成考試成績 |
| 深淺色、文字大小 | 是，外觀共用 key | 新教材之間沿用使用偏好 |
| 本部分／題組索引、提示展開狀態 | 預設否 | 回到教材時可由首頁開始，答案重新收起 |
| 第三部分當步聽讀、開口、臨時選擇 | 預設否 | 沒有實作完整續練就不承諾恢復 |
| 第七部分當次聽力選項、暫時回饋 | 可不保存 | 可重新挑戰，與已練習勾選分開 |

- 每個單元使用不同的學習儲存 key；外觀設定與學習紀錄分離。不得將所有新單元都寫入第七天 key。
- 自動保存於輸入或勾選時觸發，不需要「存檔」或「匯出」。不要全頁重繪導致輸入焦點跳掉或中文字組字中斷。
- 從 localStorage 讀取資料時做型別與範圍檢查；只接受可用欄位，錯誤 JSON 不讓整頁壞掉。輸入再呈現時安全轉義。
- 儲存失敗時仍可練習，顯示「此瀏覽器目前無法保存，關閉後將不保留本次紀錄」等準確說明。
- 說明紀錄留在此瀏覽器。以網址開啟時需同一來源；不同主機名稱、port、瀏覽器或裝置不保證共用；`file://` 的儲存行為依瀏覽器，需實測。
- 不清空 localStorage、不覆蓋其他單元的 key；移除舊功能入口不代表可以刪掉已存歷史資料。

## 6. 不提供匯出入口

本系列已決定不用匯出檔案。頁首、第一部分保存提示、第六部分、第七部分、錯誤訊息與頁尾都不能出現「匯出／下載我的紀錄」的入口或引導。

新教材不新增下載函式。維護舊教材時，未使用的歷史匯出函式不代表需要保留 UI，也不必為移除按鈕而擴大成危險的資料清理。文件與來源模板不可在之後建置時重新加回按鈕。

## 7. 內容與程式分工

不用強制使用某個框架，但至少把以下資料概念分清：

| 資料組 | 最少應表達的欄位 |
| --- | --- |
| 課程 | 單元識別、主題、核心能力、課前課後共用任務、七部分名稱 |
| 句型卡 | 識別碼、中文用途、英文、中文意思 |
| 短問答 | 識別碼、對方提問及中文、學生任務、兩層提示、替換回答情境與提示 |
| 互動流程 | 流程與步驟識別、對方台詞、學生任務、物件操作、合理結果、回饋、狀態變化 |
| 特定情況 | 識別碼、中文任務、關鍵字、範例、回答欄位 |
| 師生任務 | 識別碼、角色與第一句、接續方向、目標、條件標籤、接話卡、卡住提示 |
| 自評能力 | 穩定識別碼、以「我能……」表達的能力敘述 |
| 課後任務 | 音訊文字與中文、選項與理由、口說任務、提示、完成勾選 |

頁面從資料產生實際數量與選取狀態，不能將「5 組」「第 17 步」散落在標題、if 判斷及按鈕。更換主題時同時重寫例句、條件與後續回應，不只是替換主標題。

教材可獨立開啟；若使用來源檔加建置腳本，生成 HTML 包含所需樣式與程式，並檢查實際離線需求。語音是瀏覽器能力，不能承諾所有聲音都離線可用。
