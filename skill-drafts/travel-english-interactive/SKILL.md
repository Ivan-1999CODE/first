# 成人旅遊英文互動教材

本 skill 是可實作的教材規格。預設學生為成人英文初學者，老師在旁帶領，師生共看同一個畫面；課後部分讓學生自行複習。介面引導用繁體中文，練習內容用自然、簡短的英文。使用者當前要求優先於本規格。

## 讀取方式

不要只讀本頁的七部分摘要就開始製作。

- **製作完整新單元：** 讀完 [七部分畫面與流程](references/lesson-flow.md)、[共用介面與資料規則](references/interface-and-state.md) 及 [驗收清單](references/acceptance.md)。用 [第七天案例](references/day7-example.md) 確認實際內容如何套入規格。
- **修改既有單元：** 讀共用規則與該部分的流程、案例和驗收項目；不因小改動重做整個課程。
- 參考檔已包含文字版面圖、初始狀態、操作結果、資料需求與實例。原專案不在同一台電腦時，也應能依文件建立教材；不要依賴一個失效的本機路徑。

## 已確認的固定標準

1. 每一回都包含七個小部分，保留相同教學順序、主要區塊與操作格式。第一部分的內容順序固定為「主題介紹 → 課前嘗試與回答欄 → 任務概覽與入口」；先留下第一次說法，再看任務卡。各部分標題可隨主題改寫，但意義要對應。
2. **第二部分固定兩個入口：「我想怎麼說」與「對方問，我來答」。** 第二個入口依角色改成「店員問，我來答」「櫃檯問，我來答」等。不要顛倒成「問店員，我來答」。
3. 「我想怎麼說」包含提問、描述、需求與決定，不再分成我的提問／我的回答。「對方問，我來答」一次練一個意思的一問一答，不把長對話塞進這裡。
4. **句型與短問答的數量不固定。** 畫面格式固定，數量依單元核心任務決定；所有計數、下一組與完成判斷由實際資料產生，不能寫死第七天的 12 句或 5 組。
5. 第三部分練完整流程，第四部分練特定情況，第五部分練真人整合應用；三者不可做成重複的選擇題。
6. 第五部分師生共看同一畫面，標出誰先開口與中文第一句，老師可勾任務目標；老師引導預設收在側邊，需要時打開。
7. 第六部分用第一部分的同一道題比較前後作答；每項能力分別以 1 格黃、2 格黃、3 格綠表示需要多少協助。師生共同口頭回饋，不新增必填回饋表單。
8. **右上角固定提供放大文字與深淺色切換。** 記住使用者選擇；以共用外觀設定支援之後的新單元。
9. **不提供匯出、下載作答或列印紀錄按鈕，不加入引導學生匯出的文案。** 以瀏覽器自動保存作答、目標勾選、自評與完成紀錄。
10. 採簡潔的 Apple Design 視覺與互動原則，優先確保教學清晰度與成人閱讀需求。示意插圖、情境物件和主題色可依內容調整，不能改掉上述流程。

## 七部分一覽

| 部分 | 教學功能 | 主要畫面 |
| --- | --- | --- |
| ① 課前嘗試 | 留下第一次表達，建立比較起點 | 主題介紹 → 沒有完整答案的課前情境與輸入區 → 任務概覽與入口 |
| ② 隨身句與短問答 | 主動表達自己的意思；聽懂對方後短答 | 兩個切換入口：句型卡片網格／一次一組的聽答練習卡 |
| ③ 互動流程 | 練完整辦事順序 | 對方說話與開口引導區＋會隨選擇變化的場景操作區 |
| ④ 特定情況 | 針對一個需求或問題自行組句 | 情境選擇、情境與收起的提示、分開保存的回答欄 |
| ⑤ 師生角色扮演 | 和真人接話並完成溝通目標 | 中文開場、任務勾選與目標；側邊收起教師接話卡 |
| ⑥ 看看我的進步 | 比較表達與協助程度 | 同題重答、前後對照、三格自評、共同口頭回饋文字 |
| ⑦ 課後挑戰 | 自己再聽、說、用一次 | 可重試的聽力任務＋短口說任務與完成勾選 |

## 製作順序

1. 從對話確認主題、核心需求、學習程度、單元編號與輸出位置。已知資訊不重問；正在討論時先整理方案，已授權製作時直接實作。
2. 查看現有教材、來源與建置方式。修既有單元時先確認儲存 key 與欄位，避免覆蓋舊作答。使用者只要求新單元時，不自行改版所有舊課。
3. 先列出「這一課結束後能辦成什麼事」，再決定課前／課後同題、第二部分句型與短問答、第三部分流程、第四部分變化和第五部分真人目標。這份內容映射應一致，但不必增加一輪審批。
4. 依共用介面規格建立頁首、單元導覽、七部分選單與主內容區，再按流程文件實作。不要將七部分只排成七張靜態說明卡。
5. 將題目與畫面分離成結構化資料，讓數量可變；操作結果、後續台詞與視覺物件共用同一份情境狀態。
6. 接上保存、語音替代路徑、深淺色、文字大小與鍵盤操作。延續原專案時交付內嵌所需資源、可獨立開啟的 HTML；修改來源後重新建置。
7. 使用驗收清單檢查功能、內容與畫面，執行既有適用測試，最後交付檔案或預覽。未獲授權不自行發布或推送。

## Apple Design 設計依據

製作新介面或動態時，參考 Emil Kowalski 整理的 [Apple Design 規範](https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md)，讀取與此次設計相關的原文段落。這是第三方整理，並非 Apple 官方文件。若來源暫時無法取得，依下列摘要及本地介面規格繼續，不假裝已核對原文。

- 按下即時回饋，避免不必要的延遲；操作過程也要反映狀態。
- 有動畫時可被新的操作中斷，從當下畫面狀態接續；不因轉場鎖住輸入。
- 展開內容與觸發位置保持關係，進出方向一致。
- 拖曳只在情境有需要時採用；跟隨指標，有慣性的互動才使用適當彈簧／回彈，並提供點擊與鍵盤替代。
- 用字級、字重、行距、留白與少量層次區分重要性。透明度和陰影不能降低文字可讀性。
- 尊重減少動態、減少透明度與提高對比偏好，仍提供可理解的靜態或溫和回饋。

本 skill 的教學安排、無匯出、外觀控制及自評規則仍是教材要求；不為了套用動態風格加上不必要的手勢、套件或步驟。

## 判斷邊界

- 對方台詞的目標是聽懂，學生自己的句子才是主要口說練習；不要要求背熟雙方台詞。
- 短問答不要求唯一逐字答案；偏好選擇可有多個合理結果。客觀資訊題才判斷選擇是否符合情境。
- 朗讀與「我已開口」勾選不是語音辨識，不宣稱錄音、發音判斷、口說自動評分或教師私密畫面。
- 不把資料同步、AI 對話、登入、麥克風或跨裝置保存當成標準功能；如使用者提出，另依需求設計。
- 不放回已刪除的固定宣傳句「成人旅遊英文 · 課堂 2 × 50 分鐘 · 課後 8 分鐘」。
