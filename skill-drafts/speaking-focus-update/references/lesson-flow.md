# 七部分畫面與流程

這份文件定義固定呈現格式。主題、英文、插圖、句型數、短問答數及情境步數可以改變；不要把第七天的內容數量當成模板常數。以下版面圖為桌面閱讀順序，窄螢幕的堆疊規則見 [共用介面與資料](interface-and-state.md)。

## ① 課前嘗試：先留下一次真實的表達

### 目的與邊界

讓學生看懂今天要辦什麼事，先試著說，留下學習前的表達。這不是要學生答對的測驗，也不要先展示整份標準對話。老師可協助記錄學生原本說的英文，暫時不把回答潤飾成課後版本。

### 畫面與初始狀態

```text
主題短標／課名                       主題示意圖
一句說明今天能做什麼                 與本課任務相關的物件
[先學隨身句] [進入互動情境]

先試著說，不急著找答案
具體中文情境與「你會怎麼說？」
[第一次的嘗試：可輸入文字]
單字或短句也可以；自動保存說明

任務概覽卡片                       已練習 X / N
任務名稱、中文摘要、進入按鈕
```

- 首次進入依序顯示主題介紹、課前情境與回答欄，最後才是任務概覽與入口；已有紀錄時恢復內容。
- 「先試著說」整個區塊（標題、情境、回答欄與保存說明）放在任務概覽上方；不能只移標題、把輸入欄留在任務卡下方。桌面與手機都遵守相同閱讀順序。第七天即為「先試著說」在「兩次試穿，兩種換尺寸的需要」前面。
- 課前情境和第六部分必須使用同一份題目資料。不要只保持類似主題，卻更換已知條件或要求。
- 首頁任務卡可直達第三部分某個流程，但不強迫填完文字才能進入其他部分。
- 任務完成記號反映第三部分已完成的流程，不以點開卡片計為完成。

### 操作、提示與保存

學生讀情境 → 先口頭試說 → 學生或老師記下原句 → 前往第二部分。此區不顯示英文完整範例，不自動校正、不打分。`before` 保存第一次回答；只有使用者實際編輯此欄才改變它，第六部分的新回答不能覆蓋它。

### 第七天示例與驗收

題目：想試穿藍色上衣，不知道試衣間在哪，試穿後太緊想換大一點。學生可只寫「try on / too small」。第六部分必須能看到這個原始版本。第一次未填也能完成課程，回顧區用文字說明尚無紀錄。

## ② 隨身句與短問答：固定兩個入口

### 目的與分工

**「我想怎麼說」**是把自己的意思轉成英文的句型工具箱，包含提問、描述感受、提出需求及做決定；不要再切成「我的提問／我的回答」。

**「對方問，我來答」**練習聽懂一個問題後接一句自己的回答。一次集中一個意思，通常是一句提問配一個單字或短句；必要時可以兩個很短的句子。完整多輪辦事流程留給第三部分，真人延伸接話留給第五部分。

兩區可以重複出現同一句學生用語：前者學「這個意思怎麼說」，後者學「聽到什麼時候可以這樣回」。不要為避免重複而刪掉必要句子。

### 固定頂部結構

```text
本區標題與一句使用說明
[我想怎麼說                 ] [店員問，我來答             ]
[N 句隨身英文               ] [M 組情境問答               ]
                       ↓ 只顯示所選模式的內容
```

- 初次進入預設「我想怎麼說」，兩個入口的選取狀態要明確。
- 切換只更換第二部分內容，不開新頁、不切到其他部分、不清除其他作答。切換時停止上一段朗讀。
- N 與 M 來自實際資料長度。修改主題或數量後，模式副標、情境索引、上一組／下一組及末組判斷一起更新。
- 對方角色名稱依場景更換；例如飯店為「櫃檯問，我來答」。固定的是「對方先問，學生回應」的意思。

### A. 我想怎麼說：卡片格式

```text
01 / 中文用途                  02 / 中文用途
英文句子（視覺重點）            英文句子（視覺重點）
▸ 看中文意思                   ▸ 看中文意思
[▶ 聽發音] [慢速]              [▶ 聽發音] [慢速]

03 / 中文用途                  04 / 中文用途
……

本課容易混淆的用語提醒（有實際需要才提供）
[上一部分]                     [進入互動流程]
```

- 桌面兩欄，手機單欄。每張卡固定包含：序號、簡短中文用途、英文句子、收起的中文意思、一般朗讀、慢速朗讀。
- 英文直接顯示；完整中文翻譯預設收起，中文用途維持可見。例如「詢問試穿」是用途，「這件可以試穿嗎？」是翻譯。
- 按朗讀只讀該卡英文；慢速讀同一句，不要把中文用途一併念出。
- 用途按實際使用順序安排，例如先詢問，再描述問題，最後確認決定；不用僵硬的問句／答句分類。
- 底部補充只說與本課直接相關的差別，例如 size 與 fit、tight 與 loose，避免增加長篇文法課。
- 不強制逐卡勾選或計分，不把聽過卡片當成已掌握。

**內容資料至少有：**穩定識別碼、中文用途、英文、中文意思；可選的用法提醒獨立於核心句子。

### B. 對方問，我來答：畫面格式

```text
[1. 招呼] [2. 尺寸] [3. 顏色] ……（情境選擇）
┌ 本組中文名稱                              i / M ┐
│ 對方問你                    │ 換你回答          │
│ 小插圖／角色提示            │ 先試著說          │
│ [▶ 聽對方說] [慢速重播]     │ 中文任務與已知條件│
│ ▸ 對方英文與中文            │ ▸ 需要一點關鍵字  │
│                             │   ▸ 完整參考說法  │
│                             │ 換成你的答案      │
│                             │ 一個替換條件      │
│                             │ ▸ 關鍵字／範例    │
│ [上一組]                         [下一組]       │
└────────────────────────────────────────────────┘
```

- 桌面左側為對方輸入，右側為學生回答；手機依序排「對方 → 學生 → 換答案 → 組間導覽」。
- 一次只展開一組問答。上方可直接選情境，底部也能上一組／下一組。第一組不允許上一組；末組提供進入第三部分的入口，不跳出不存在的題目。
- 初始可見中文情境、朗讀按鈕與學生任務；對方英文逐字稿、中文翻譯、關鍵字、完整回答皆收起。
- 學生中文任務交代回答所需資訊，但不直接給英文答案。例如「你平常穿 M 號，告訴店員」提供情境，不是測學生猜老師心中的尺寸。
- 原則上先聽；聽不懂或無法播放時，自行展開對方英文與中文即可繼續，不把音訊播放成功當成唯一入口。

### B. 一組的完整操作流程

1. 按「聽對方說」，聽一個短問題；可以重播或慢速。
2. 依中文任務，先用自己的聲音回答。此區不加第三部分的雙勾選解鎖，讓老師控制練習節奏。
3. 卡住時展開「需要一點關鍵字」。只給能組出句子的少量詞組。
4. 仍需要協助，再展開下一層完整參考回答；可聽參考句。答案是可用的說法，不是唯一逐字標準。
5. 做「換成你的答案」：改一個條件，如 M 換 L、藍色換綠色、需要幫忙換成先看看；保持同一溝通功能。
6. 前往下一組，清掉上一組的提示展開狀態並停止舊音訊，避免一進新題就看到答案。

這裡不需要輸入欄、不自動保存口頭回答、不自動打勾或評分。只需當次記住正在看的模式與組別；重新開啟可回預設模式。說明一句「直接開口練習即可；這裡不錄音，也不自動評分」。

**每組資料至少有：**識別碼、情境名稱、對方英文、中文意思、可選的聽懂提醒、學生中文任務、回答關鍵字、參考短答、替換情境、替換關鍵字及參考短答。

### 第二部分完整示例

| 欄位 | 詢問尺寸這一組 |
| --- | --- |
| 對方英文 | What size do you wear? |
| 對方中文 | 你穿什麼尺寸？ |
| 學生任務 | 你平常穿 M 號，試著告訴店員。 |
| 第一層提示 | medium / please |
| 完整短答 | Medium, please. |
| 換答案任務 | 如果你穿 L 號呢？ |
| 替換提示與範例 | large / please → Large, please. |
| 老師核對 | 有聽懂是在問尺寸，且回答的尺寸符合任務即可。 |

**驗收：**兩個入口確實能切換；A 有句型卡及收起的中文；B 一次一組、先聽後答、兩層提示與替換練習；不是把兩區都做成同一份英文清單，也不是把 B 做成選擇題測驗。

## ③ 互動流程：讓學生在場景裡辦成一件事

### 目的與畫面

學生走過連續的辦事順序，對方的話、自己的回應與場景操作互相連動。只在文字下方加「下一頁」不算完成這部分。

```text
標題、使用說明、流程情境選擇
本流程摘要                                  [重新開始]
┌ 對方說話與學生回應 ┐    ┌ 情境操作區                ┐
│ 第 i / N 步、進度條 │    │ 本步該操作什麼             │
│ [聽] [慢速]         │    │ 衣架／鏡子／菜單／票機等   │
│ ▸ 逐字稿與中文      │    │ 可點擊的物件與選取狀態     │
│ □ 已聽完或讀完      │    │ 目前的選擇／尺寸／路線摘要 │
│ 中文「換你說」任務  │    │ 操作後的成功或重試回饋     │
│ ▸ 關鍵字 → 完整範例 │    └──────────────────────────┘
│ □ 已用自己的聲音說 │
│ [上一步] [下一步]   │
└────────────────────┘
```

### 學生開口區：固定標記與色框

沿用已確認的第八天樣式，讓學生一眼辨識「現在看哪裡、要說什麼」。

- 在「換你用英文說／換你開口／先開口問」標題旁放非按鈕標記 **「↓ 看這裡，換你說」**。保留該步原本的先問或回答順序；窄螢幕可讓標記換行到標題下方。
- 將中文口說任務及原有收合提示放入暖黃色底、圓角、有明確邊框且左側較粗的區塊。任務字體稍加粗；色框標示學生要表達的意思，不代表已完成或答對。
- 關鍵字與完整參考回答仍預設收起。展開完整英文時，以較淡底色和細框獨立圈出參考說法；不要因加色框而提前公布答案。
- 對方台詞、聽讀確認、已開口勾選、物件選項與下一步控制留在各自區域；不將整頁或教師台詞一起染成黃色。
- 參考配色：淺色底 `#fff4dc`、邊框 `#c38b35`、文字 `#59380e`；標記底 `#8a510c`、白字。深色底 `#3c301c`、邊框 `#c79850`、文字 `#fff0cd`；標記採淺金底與深字。背景、邊框和文字需一起調整。
- 用箭頭、文字及邊框共同引導，不只靠顏色；不用閃爍或循環動畫。手機、放大文字及提高對比偏好下不裁切、不水平溢出。
- 每個流程步驟都套用，切步、重選或重開後仍存在；不變更原本的題目、語音、解鎖條件與保存資料。舊課若把口說練習放在其他部分，套用到既有對應口說任務，不為加樣式改造聽力題。
- 延續 Travel Lab 專案時，樣式共用來源為 `assets/speaking-focus.css`，各來源渲染保留 `speaking-heading`、`speaking-cue`、`speaking-task` 結構。建置時內嵌共用樣式，避免只改生成 HTML，或依賴外部 CSS 才能離線使用。

### 固定互動順序與狀態

1. 初始可播放對方台詞及展開逐字稿；尚不能操作物件，也不能下一步。
2. 勾選「我已聽完，或已讀完逐字稿」後，開放「我已用自己的聲音回應」勾選。
3. 學生看任務、自行開口；可展開關鍵字及更深一層的範例。第二個勾選只是自我確認，不需要麥克風。
4. 兩項皆確認後開放場景物件操作。若取消前一項，後續確認及本步選擇失效，不能用舊答案越過此步。
5. 點擊符合情境的物件後，立即更新選取、場景、摘要與回饋，才開放下一步。不要只改選項底色卻沒有情境結果。
6. 客觀資訊選錯給重試提示，保留本步讓學生重聽或重選；偏好題可以多個答案都合理，不假裝只有一個正確顏色。
7. 進入下一步重設當步聽讀、開口、選項與回饋；保留流程所需的既有選擇，使後續台詞及物件一致。

### 場景與回饋要求

- 第七天的尺寸選擇應反映在鏡中合身度、衣服標籤及店員確認句。飯店主題可改為房型與房卡，交通主題可改為路線與車票。
- 用語必須跟目前選擇一致；先選綠色，不能結尾說「藍色 M 號對嗎」。缺貨條件會限制可選項或給相符回饋。
- 以點擊／觸控物件為主要操作就能形成互動；不必所有題都拖曳。有拖曳時提供點擊及鍵盤等效操作。
- 上一步允許重新思考，但需清掉被改動選擇之後的依賴結果。重新開始清本輪流程，不清課前作答、自評、其他情境紀錄。
- 完成畫面顯示最後結果、已完成標記與一句口頭總結任務，再給重練／另一流程／第四部分入口。

### 資料、保存與驗收

每步資料至少包含：對方英文與中文、學生任務、關鍵字與範例、操作種類、選項、可接受結果、重試原因、成功回饋及對情境狀態的影響。後續需要的狀態明確傳遞，不用散落字串假裝連動。

保存完成的流程識別碼。本輪所在步、聽讀勾選和臨時物件操作預設不跨重新整理恢復；不要承諾逐步接續，除非另外實作與驗證。

**驗收：**不能未開口就跳過；文字替代路徑可完成；錯誤可重試；合理分支不被誤擋；回頭改答案後結果仍一致；物件變化看得出來。

## ④ 特定情況：集中練一句需求怎麼說

### 目的與畫面

把流程裡的一項需求抽出，給新的條件，讓學生自行組句。這裡不用再走完整買東西流程，也沒有連續對方台詞的解鎖機制。

```text
標題、先口說再記錄的說明
[情境 A] [情境 B] [情境 C] ……
┌ 這次遇到的情況          ┐  ┌ 我的說法                ┐
│ 中文情境與具體需求       │  │ [多行輸入欄]             │
│ ▸ 關鍵字                │  │ 一句核對溝通重點的提醒   │
│   ▸ 參考說法與朗讀      │  └────────────────────────┘
└────────────────────────┘
```

- 情境不是只有標題；必須交代角色、問題、已知資訊及希望達成的事。
- 初始顯示任務與回答欄，所有英文提示收起。既有回答恢復到對應情境。
- 學生讀情境 → 先口說 → 需要時開提示 → 記下自己的版本 → 與老師核對是否清楚表達需求。
- 不以文字完全相符或拼字自動判定口說正確。提示只是範例，不塞唯一答案的選擇按鈕。
- 不同情境的回答各自保存，切換時不能互相覆蓋；切換後提示重新收起。
- 核對文案符合本情境：換尺寸看問題及目標尺寸，換色看替代需求與最後偏好，不一律套「有說不合身嗎」。

**第七天示例：**藍色 S 號太緊，說明問題、問大一點並指定 M 號。可用三個短句完成，不需重演進店招呼、找試衣間與結帳。

**驗收：**學生不用走第三部分的步驟就能練特定需求；每份回答分開保存，提示可選，老師能看出本題要檢查什麼。

## ⑤ 師生角色扮演：共看畫面，自然接話

### 目的與初始畫面

讓學生把前面學過的能力用在真人互動。老師扮演情境對方，根據學生實際說法接話，網站只提供任務與帶領支架。

```text
角色說明：學生當顧客，老師當店員，共看畫面
[任務 A] [任務 B] [任務 C] ……
┌ 學生任務（主區）                       ┐ ┌ ▸ 老師引導 ┐
│ 名稱、情境、必要物件／比較圖           │ │需要時打開  │
│ ① 學生先說／老師先說                   │ └────────────┘
│ 「中文第一句」                         │
│ 請用自己的英文表達，不必逐字翻譯。     │
│ ② 老師接話／學生回答：簡短接續說明     │
│ 這次要完成的事               X / N 項  │
│ □ 可觀察的溝通目標                     │
│ □ ……                                  │
│ 完成目標：本次談清楚哪些事             │
│ [記下一句真正用到的英文]               │
└───────────────────────────────────────┘
```

- 開場角色依情境判斷，並給**真正可說的中文第一句**，不能只寫「由學生開始」。例如學生先說「這件衣服穿起來太緊了」。
- 若老師先說，同樣將中文第一句放主畫面；老師英文參考藏在引導內。
- 目標是可勾選的溝通行為，如「說明太緊」「詢問大一點」「確認最後尺寸」，不是「說得很棒」或「背出整段」。目標數量依情境，不寫死四項。
- 老師完成一項就能勾一項，亦可取消；不用依清單順序說，不要求每字符合範例。顯示已完成／總目標數。
- 主畫面的物件有助指稱與比較，但不要顯示所有教師庫存條件或學生完整示範答案。

### 教師引導展開後的固定順序

1. **先確認起點：**誰先說、中文第一句；老師先說時提供英文開場與朗讀，學生先說時提醒先等待學生開口。
2. **條件標籤：**只用短標籤列出庫存、票價、房型等老師此時需要的條件。
3. **快速接話卡：**標題「聽到學生……你可以接」，提醒找符合當下的卡，不必逐卡照念。
4. **學生卡住了：**預設收起；展開先看中文引導及少量關鍵字，完整學生參考說法再收於下一層。
5. **帶領小提醒與完整條件：**預設收起，放較長補充，不讓它擋住老師最需要的下一句。

每張接話卡固定順序：

```text
學生要求換大一點 →          （中文觸發條件）
Here is the medium.          （醒目英文，可依情境替換）
How does it fit?
提供 M 號，再問穿起來如何。 （中文用途說明）
[▶ 聽這句]
```

- 老師能在幾秒內用觸發條件找到回應；不要藏在長篇逐字對話中。
- 學生已講出尺寸就不重問尺寸；已選藍色，教師確認句要跟著選擇變更或清楚標出替換欄位。
- 可接受不同路徑；買、不買分別有自然的接話，不把完成任務等同一定購買。
- 師生同畫面，展開後兩人都能看到；「收起」不等於私密教師端。

### 保存與驗收

每個任務有自己的目標勾選陣列，切換與重新開啟仍保留；新建教材的口說筆記也依任務獨立保存。第七天現有 `pairNote` 是共用欄，若改成分題，先處理舊資料遷移，不可默默清掉。

教師引導及深層提示不保存展開狀態；切換任務或重新進入時先收起。所有勾選完成是「目標已做到」，不顯示自動評分。

**驗收：**不用開教師引導也知道誰先說、第一句是什麼、要達成什麼；打開後迅速找到下一句；各任務勾選互不干擾。

## ⑥ 看看我的進步：同題比較與協助程度

### 目的與畫面

讓老師與學生看到具體改變，並確認下次需要哪種練習。提示工具、自評選項與回饋是不同功能，不混在一起。

```text
回到同一題：完整重現第一部分的中文情境
▸ 看關鍵字
  ▸ 看完整範例（可朗讀）

┌ 第一次的我             ┐ ┌ 現在的我               ┐
│ 原始課前回答，只讀      │ │ [現在的回答，可輸入]    │
└───────────────────────┘ └────────────────────────┘
一起核對：本題各項溝通需求是否都有表達？

現在的我，能做到哪一步？
能力 A → [三格程度條] 文字狀態
[看完整範例] [看關鍵字] [能獨立完成]
能力 B → ……

留下一句具體回饋。
老師與學生一起找出：這次做到了什麼，下次要多練習哪一步。
```

### 操作與提示

1. 先不看提示口頭回答同一道課前題；關鍵字與完整範例預設收起，依需要開啟。
2. 寫下現在的說法，再對照第一次回答。第一次未填時顯示尚無紀錄與可回第一部分補上的提示，不代寫一個較差版本。
3. 老師與學生依溝通重點核對，不使用字串相似度當口說成績。
4. 對每項能力選「這次實際需要的協助」，可隨時改選；不要因學生開過提示就自動替他選程度。
5. 最後一起口頭說出本次做到的事及下次要練的步驟。

### 自評的精確狀態

| 選擇 | 程度條 | 狀態文字 | 按鈕 |
| --- | --- | --- | --- |
| 尚未選擇 | 三格皆中性色 | 尚未自評 | 都未選取 |
| 看完整範例 | 第 1 格黃，其餘中性色 | 看完整範例 · 1 / 3 格 | 該項黃底／黃邊，說明「有完整句子，我能跟著表達。」 |
| 看關鍵字 | 第 1、2 格黃，第 3 格中性色 | 看關鍵字 · 2 / 3 格 | 該項黃底／黃邊，說明「給我幾個詞，我能自己組句。」 |
| 能獨立完成 | 三格全部綠 | 能獨立完成 · 3 / 3 格 | 該項綠底／綠邊，說明「不看提示，我也能說清楚。」 |

- 每一項能力各自有三格，不做一整課合計的星星數或總分。選回第一或第二程度時，綠格要退回正確的黃色與中性色。
- 提示的「看完整範例／看關鍵字」按鈕是開內容；自評的同名按鈕是標記協助程度。兩者不能互相取代或誤觸。
- 三格等寬，使用顏色、格數文字與選取狀態共同表達；深色模式仍是前兩級黃、第三級綠。
- 能力項目依本課核心任務設計，不必永遠三項。
- 共同回饋區只保留上圖的標題與一句引導，不新增回饋輸入框、星等、下載或匯出控制。

### 保存與驗收

課後回答與各能力自評保存；課前回答保留原樣。既有單元的舊回饋即使不再顯示輸入框，也不因此刪除資料。

**驗收：**同題、不同欄保存；沒有紀錄時不造資料；自評能在四種狀態間正確顯示；變色不被當成口說正確率；教師口頭回饋區不被表單取代。

## ⑦ 課後挑戰：聽一次，再自己說一次

### 目的與畫面

以短任務練習已學能力，換一些條件來確認能遷移使用；不突然加入大量未教過的句型。

```text
課後挑戰標題與簡短說明
┌ 1. 聽懂關鍵資訊            ┐ ┌ 2. 說自己的版本             ┐
│ 中文問題／任務條件          │ │ 新的中文情境                │
│ [聽] [慢速]                 │ │ [自己的說法，多行輸入]      │
│ ▸ 英文逐字稿與中文          │ │ ▸ 關鍵字 → 完整參考說法     │
│ [選擇 A] [選擇 B] ……        │ │ □ 我已寫下自己的版本        │
│ 正確／重試回饋              │ │ □ 收起提示大聲說一次        │
│ □ 我已練習聽懂關鍵資訊      │ │ 已練習 X / N 項             │
└───────────────────────────┘ └─────────────────────────────┘
```

- 聽力題先提供已知任務，再播一小段英文；干擾選項只改顏色、時間、位置等關鍵資訊，仍應合理。
- 初始選項未選，回饋不顯示，逐字稿收起。選擇後立刻顯示結果；答錯可重播、看文字或重選，不封鎖任務。
- 正確回饋說明哪幾個詞提供證據，錯誤回饋提醒重聽哪項資訊，不羞辱或直接判定程度差。
- 口說任務先說再記錄，需要時才開提示；建議收起提示後再說一次。若提到手機錄音，要明確是學生自行使用手機，不假裝網頁已內建錄音。
- 完成勾選由學生自己確認「已練習」，不自動等同通過測驗。
- 保存自己的回答與完成勾選；聽力當次選項可不保存，重新進入能再練。不提供任何匯出按鈕。

**第七天示例：**聽懂 green／medium／on the right，再寫「綠色 L 太鬆，換 M 後合身並決定買」的短對話。

**驗收：**無老師在旁也知道先做什麼；聽力可重試且無音訊時有文字路徑；回答與勾選保存；完成數字來自實際勾選。
