# 教材驗收清單

新單元使用整份清單；局部修改只驗證受影響行為與必要回歸。不要為了清單重新改動沒有問題的功能，或為低風險文字修改建立大量測試。

## 內容與教學分工

- [ ] 七部分完整，第一與第六部分使用同一題目；第一次回答與現在回答分開。
- [ ] 第一部分在主題介紹後先放完整課前嘗試區，再放任務概覽與入口；桌面及手機都不是只把標題移上去。
- [ ] 第二部分能切「我想怎麼說／對方問，我來答」，各自遵守卡片與短問答格式。
- [ ] 句型與問答數量沒有固定配額；數量顯示、上一組／下一組由資料產生，不殘留第七天硬編碼。
- [ ] 短問答先聽懂再短答，一組練一個意思，包含替換回答；不要求背熟對方台詞。
- [ ] 第三部分是連續流程與物件互動，第四是特定需求的自由表達，第五是老師接話的真人任務。
- [ ] 角色、庫存、尺寸、路線或其他條件一致；合理偏好不被錯判為唯一答案。
- [ ] 第五部分不用打開教師提示也能知道誰先說、中文第一句及勾選目標。
- [ ] 第六部分是協助程度自評，沒有偽造口說成績或課前回答；共同回饋區只留標題與引導文字。
- [ ] 第七部分能自行完成，包含重試回饋，不超出前面教過的主要能力。

## 瀏覽器操作與狀態

- [ ] 第二部分兩個入口、任一中間題組與末組可到達；新題組的逐字稿和提示預設收起。
- [ ] 句型卡英文可見，中文翻譯按需展開；短問答的完整答案沒有初始外露。
- [ ] 第三部分未確認聽讀與開口時不能操作物件；文字替代路徑可通過流程。
- [ ] 完成一條主要路徑，並測一個錯誤重試、一個合理分支及回頭改答案；視覺、摘要、台詞一致。
- [ ] 教師引導展開後有起點、條件標籤、快速接話卡、收起的學生提示；切任務後重新收起。
- [ ] 同一任務可以勾選及取消，各任務紀錄不混用。
- [ ] 自評未選、1 格黃、2 格黃、3 格綠，以及從綠改回黃均正確；文字狀態與選取一致。
- [ ] 課後聽力能從錯誤重選到正確，完成勾選不冒充測驗成績。
- [ ] 音訊切換不疊音，無法播放時有文字路徑；不要求未授權的錄音權限。

## 外觀與閱讀

- [ ] 各流程的學生開口區都有「↓ 看這裡，換你說」標記、暖黃色任務框；完整英文仍收合，展開後另有內框。
- [ ] 標記不是可點擊控制，也不是完成／正確提示；切步後仍保留，深色、手機與放大文字下可讀且不溢出。


- [ ] 右上角同時有放大文字與深淺色控制，切七部分後仍可操作。
- [ ] 淺色、深色各看過句型卡、操作場景、教師引導與進步頁的代表狀態，文字與控制有足夠對比。
- [ ] 深色不改掉具有教學意義的物件顏色，黃綠自評不被一般按鈕樣式覆蓋。
- [ ] 放大文字後正文、提示及按鈕仍可讀，手機不水平溢出，卡片和控制不互相覆蓋。
- [ ] 窄螢幕選單可展開，兩欄合理堆疊，教師引導可找到；鍵盤能完成主要操作。
- [ ] 減少動態時仍有可理解回饋，焦點與選取不只靠顏色。

## 保存、輸出與專案整合

- [ ] 重開後恢復課前／課後、特定情境回答、目標勾選、自評及課後紀錄；保存新單元不改舊單元。
- [ ] 外觀選擇及文字大小能保存；格式異常或儲存受阻時頁面仍可使用。
- [ ] 沒有任何匯出或下載紀錄按鈕，沒有「關閉前請匯出」等過時文案。
- [ ] 新增單元後各天導覽互相可達，當前頁標記正確，所有相對連結指向現存檔案。
- [ ] 修改來源後建置；回讀生成檔，確認實際內容與來源一致，重建不復活已刪功能。
- [ ] 執行既有相關測試及必要功能測試；不以「腳本執行過」代替檢查通過結果。
- [ ] 交付時區分程式測試、檔案核對、瀏覽器實測及未測項目，不聲稱未執行的驗證。

## 驗證方法與界線

文字／HTML 檢查適合確認連結、七部分數量、資料欄位、生成內容與無匯出入口；互動測試適合確認保存、分支、重試與依賴狀態；瀏覽器操作及截圖適合確認提示、對比、焦點與排版。三種證據不能互相冒充。

本清單是未來製作教材時使用，不代表只修改 skill 文件就已完成一次新教材實測。當工作範圍是 skill 修改，驗證文件格式、引用路徑、規則一致性及案例準確性即可，清楚說明尚未用新單元驗證。
